# 🔍 Análise de Dados dos Personagens dos Vingadores

Este projeto tem como objetivo analisar um conjunto de dados dos personagens dos Vingadores, originalmente disponibilizado pelo site [FiveThirtyEight](https://fivethirtyeight.com/). A ideia foi usar a linguagem Python para explorar padrões envolvendo gênero, número de aparições, mortes e outros aspectos relacionados a esses heróis ao longo dos anos.

---

## 📁 Sobre o Conjunto de Dados

- **Fonte**: FiveThirtyEight
- **Número de personagens**: 173
- **Número de variáveis**: 21
- **Informações disponíveis**: nome, ano de introdução, gênero, número de aparições, status de vida, entre outras.

---

## ⚙️ Tecnologias Utilizadas

- Python (Google Colab)
- Bibliotecas: `pandas`, `matplotlib`, `seaborn`, `numpy`

---

## 📊 Principais Descobertas

- **Predomínio masculino**: Cerca de 66,5% dos personagens são do sexo masculino, que também aparecem com muito mais frequência nas histórias.
- **Distribuição desigual**: A maioria dos personagens aparece poucas vezes, enquanto alguns têm números extremamente altos de aparições (outliers), o que eleva a média para 414 aparições, com um desvio padrão de 677.
- **Mortes e protagonismo**: Personagens com mais aparições também tendem a morrer mais, o que mostra que os mais relevantes passam por mais reviravoltas.
- **Presença pós-morte**: Muitos personagens masculinos continuam aparecendo mesmo após "morrer", indicando sua importância contínua na narrativa.
- **Inconsistências nos dados**: Foram identificadas 14 entradas com datas anteriores a 1939, ano da fundação da Marvel — um erro que mostra a importância da limpeza dos dados.

---

## 📌 Conclusão

Este projeto mostrou como a análise de dados pode ser uma forma divertida e informativa de entender padrões por trás das histórias em quadrinhos. Vimos quem são os personagens com mais destaque, como o gênero influencia na presença nas histórias e como os dados revelam dinâmicas invisíveis à primeira vista. Além disso, reforça a importância de verificar e tratar inconsistências nos dados antes de tirar conclusões.
